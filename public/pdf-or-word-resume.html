PDF or Word Resume: Which File Should You Send?

Both can work. The right choice depends on what the employer asks for and how the file will be read.

Updated October 2026 · By QuickResume · Free · No sign-up

Quick answer

Follow the instructions in the posting first. If there are none, a text-based PDF is usually a safe default because it keeps your layout the same on every device. Choose DOCX when the employer or portal asks for Word, or when a recruiter may need to edit it.

PDF: the usual default

  • Layout, fonts and spacing stay the same on phones and computers.
  • Looks finished and is harder to change by accident.
  • Works with most modern applicant tracking systems as long as the text is real text.

The caution is how the PDF is made. Export one from a word processor or a resume builder so the words can be selected and copied. A scanned page or a screenshot saved as PDF is just a picture, and software cannot read it.

Word (DOCX): when it makes sense

  • The posting or upload form asks for .doc or .docx.
  • A recruiter or agency may need to edit or reformat your details.
  • Some older systems handle Word files more predictably. Not every system differs, so this is a precaution rather than a rule.

The risk with DOCX is formatting drift: fonts that are missing on another computer can shift your layout. Stick to common fonts.

Name the file properly

Use something a recruiter can find in a crowded downloads folder, for example Priya-Sharma-Resume.pdf. Avoid names like "resume final v3 (2).pdf". Use your own name instead of a template or tool name.

Before you upload

  1. Open the file on your phone and your computer to make sure it looks the same.
  2. Try selecting and copying text. If you cannot, it is probably an image.
  3. Check it with the free ATS resume checker for readability problems.
  4. Keep to one or two pages, as covered in how long a resume should be.

Frequently asked questions

Is PDF or Word better for ATS?
Neither is universally better. A text-based PDF or a simple DOCX both usually work. Follow the employer instructions, and avoid image-only files, tables and text boxes.

Can I convert my Word resume to PDF?
Yes. Use Save as PDF or Export in your word processor so the text stays selectable, then check that nothing moved.

What if the portal rejects my file?
Check the allowed file types and size limit. If PDF is rejected, try DOCX, and the other way around. A smaller file may help too.
