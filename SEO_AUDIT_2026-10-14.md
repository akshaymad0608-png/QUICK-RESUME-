# SEO / AEO / GEO audit — QuickResume (14 Oct 2026)

Scope: titles and meta, on-page, technical SEO, mobile, structured data, AI-search readiness (AEO/GEO), keywords and backlinks.
Method: static validator (`npm run seo:validate`), a script over the built HTML, mobile-viewport checks with Playwright, live header checks, and a read of the code.

## Data limits (read this first)

- **No keyword volumes, difficulty, backlink or competitor numbers are verified.** Ahrefs returned "Insufficient plan", Semrush returned `no_api_units`, and Able SEO returned no structured data. Every keyword idea below comes from the Search Console screenshots the owner shared plus general SEO knowledge, not from a tool.
- Search Console figures used (3 months, from the owner's screenshots): 13 clicks, 583 impressions, average position 24.6, CTR 2.2%. All 13 clicks came from the brand query "quickresume". "quick resume" had 195 impressions and 0 clicks.
- Analytics (28 days, from screenshots): 32 users, 47 sessions, 36 s average engagement; google/organic 23, direct 21, m.facebook.com 2, bing 1.
- No Lighthouse run in this pass; the earlier audit's baseline (performance 61, LCP 6.6 s on a local server) is the last measured number.

## Findings that are not fixed here

1. **Privacy policy contradicts the code.** `src/pages/PrivacyPolicy.tsx` says reading a PDF or DOCX "happens on your device". `uploadResume.ts` sends the file to `/api/extract-resume`, which passes it to the Gemini API. The policy text needs a legal-minded rewrite by the owner; this PR only fixes the marketing copy.
2. **Brand-name collision.** "quick resume", "instant resume" and "rapid resume" are generic phrases, and apps such as "Quick Resume" and "QuickResume: AI Resume Builder" already exist. This is an assumption from a web search, not tool data. Do not chase these as keywords; keep the brand clicks and target "ai resume builder" and fresher queries.
3. **Icon font is unpinned** (`@tabler/icons-webfont@latest`). It is now non-blocking, but pinning a version avoids a surprise icon change. The version was not verified from here.
4. **Core Web Vitals field data** is not available. Check Search Console → Core Web Vitals after a few weeks.
5. **Soft 404s.** Vercel rewrites unknown URLs to `index.html` (HTTP 200) and the React 404 page is `noindex`. That is acceptable, but a real 404 status would be cleaner.
6. **Large JS.** `Build` chunk 519 KB, main bundle 479 KB, `jspdf` 391 KB, `html2canvas` 202 KB. Confirm `jspdf` and `html2canvas` load only on export.
