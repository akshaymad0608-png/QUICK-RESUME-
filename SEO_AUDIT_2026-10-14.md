# SEO / AEO / GEO audit — QuickResume (14 Oct 2026)

Scope: titles and meta, on-page, technical SEO, mobile, structured data, AI-search readiness (AEO/GEO), keywords and backlinks.
Method: static validator (`npm run seo:validate`), a script over the built HTML, mobile-viewport checks with Playwright, live header checks, and a read of the code.

## Data limits (read this first)

- **No keyword volumes, difficulty, backlink or competitor numbers are verified.** Ahrefs returned "Insufficient plan", Semrush returned `no_api_units`, and Able SEO returned no structured data. Every keyword idea below comes from the Search Console screenshots the owner shared plus general SEO knowledge, not from a tool.
- Search Console figures used (3 months, from the owner's screenshots): 13 clicks, 583 impressions, average position 24.6, CTR 2.2%. All 13 clicks came from the brand query "quickresume". "quick resume" had 195 impressions and 0 clicks.
- Analytics (28 days, from screenshots): 32 users, 47 sessions, 36 s average engagement; google/organic 23, direct 21, m.facebook.com 2, bing 1.
- No Lighthouse run in this pass; the earlier audit's baseline (performance 61, LCP 6.6 s on a local server) is the last measured number.

## Findings that are not fixed here

1. **Privacy policy contradicted the code.** Fixed in a follow-up PR: the policy now states that uploads and AI text go to our server and Google's Gemini API, lists Vercel and the CDNs, describes error logging, and uses the published contact email. Have the owner (or a lawyer) read it once before relying on it as a legal document.
2. **Brand-name collision.** "quick resume", "instant resume" and "rapid resume" are generic phrases, and apps such as "Quick Resume" and "QuickResume: AI Resume Builder" already exist. This is an assumption from a web search, not tool data. Do not chase these as keywords; keep the brand clicks and target "ai resume builder" and fresher queries.
3. **Icon font is unpinned** (`@tabler/icons-webfont@latest`). It is now non-blocking, but pinning a version avoids a surprise icon change. The version was not verified from here.
4. **Core Web Vitals field data** is not available. Check Search Console → Core Web Vitals after a few weeks.
5. **Soft 404s.** Vercel rewrites unknown URLs to `index.html` (HTTP 200) and the React 404 page is `noindex`. That is acceptable, but a real 404 status would be cleaner.
6. **Large JS.** `Build` chunk 519 KB, main bundle 479 KB, `jspdf` 391 KB, `html2canvas` 202 KB. Confirm `jspdf` and `html2canvas` load only on export.

## Keyword research pass (second round)

Method: live web search of the results people actually see for the target queries (US-based search tool, so India results are approximate), plus Search Console screenshots. Ahrefs, Semrush and Able SEO were still unavailable and Google Autocomplete could not be reached, so there are **no verified volumes or difficulty scores**.

What the results showed:
- **"Resume format for freshers"** is served by India-focused sites (ResumeGyani, Kudoswall, Qarera, CollegeSathi, MakeMyCVFree). They share a pattern: one page, single column, education and projects before experience, fields for 10th/12th/graduation marks, and a free Word or PDF download.
- **"ATS resume checker for freshers / India"**: ATSMeter, Hirenix, WisGrowth and MyCVRoast lead with "no sign-up", "for freshers and government jobs" and Hindi/Hinglish feedback.
- **"Free resume builder no sign-up India"**: WorkIndia, ResumeGyani and ResumeRocket; the winners say "no watermark" and "PDF download" in the title or first line.
- **"Career objective for freshers"** and **"skills for freshers"**: Naukri Campus dominates; the advice is 30 to 50 words, role-specific, and 8 to 12 grouped skills.

Problems this exposed and the fixes:
1. `/resume-format-for-freshers` was actually a **biodata** page (title "Biodata Format for Job"). The highest-intent fresher keyword had no matching page, and the page also claimed the builder had biodata fields (date of birth, father's name, declaration) that it does not have. Fixed: the URL is now a real fresher resume format guide (section order, sample, no-experience tips), and the biodata content moved to a new `/biodata-format-for-job` page with the false claim removed (custom sections can be renamed, which is what the page now says).
2. `/improve` was titled "Free AI Resume Checker and Fixer"; it now says "Free ATS Resume Checker & Fixer — Instant Score", matching how people search.
3. Added a "skills for freshers" section to the skills guide and an "ATS checker for freshers" section to the ATS guide.

Still open (needs real data or product work):
- Free **Word/PDF downloadable fresher templates** are the pattern competitors win with. The builder exports PDF; a downloadable template library would need to be built.
- **Hindi/Hinglish feedback in the ATS checker** is a differentiator competitors advertise; it is a product change.
- A **biodata template** (date of birth, father's name, declaration fields) would justify a real "biodata maker" page.
- Confirm volumes with Ahrefs or Semrush (country IN) before writing more pages.

## Full re-audit after PRs #19-#22 (14 Oct 2026, evening)

Method: live fetch of `quickresume.business` (headers, HTML, robots, an unknown URL), local build + `seo:validate`, Playwright at 390 px (LCP/CLS, horizontal scroll, tap targets, console), web search. Ahrefs/Semrush/GSC data were still unavailable, so there are no volume, backlink or ranking numbers.

### Verified good
- Live homepage serves the new build: Consent Mode v2 default-denied, title/description/canonical, Organization + WebSite + FAQPage + WebApplication JSON-LD, 1 `h1`, prerendered body text for non-JS crawlers.
- `robots.txt` allows search and AI crawlers and lists the sitemap; HSTS, nosniff, referrer-policy, permissions-policy and a CSP are sent.
- `seo:validate`: 32 pages (30 indexable, 2 noindex), 30 sitemap URLs, 0 errors, 0 warnings.
- Mobile (390 px, local, unthrottled): no horizontal scroll on `/`, `/templates`, `/improve`, `/pricing`, a guide; CLS 0 to 0.026; every page has one `h1`; no images without alt.

### Fixed in this PR
- Unknown URLs returned a bare `NOT_FOUND` text page. A branded, noindex `404.html` is now generated (Vercel serves it with a real 404 status).
- CSP allowed AdSense hosts but not `fundingchoicesmessages.google.com`, the host a Google consent message (Privacy & messaging) loads from. Added to `script-src`, `connect-src`, `frame-src`. Caveat: Google publishes no official allowlist and recommends a nonce-based strict CSP; this host came from a third-party scan, so test the consent message after enabling it.
- Footer links and the cookie-banner privacy link were 16 to 17 px tall; padded for touch.

### Still open (needs data or an owner decision)
1. **Brand search**: a web search for `quickresume.business` returned other "Quick Resume" apps, not the site. The search tool is US-only and not authoritative, so check Search Console (Performance, query "quickresume") before drawing conclusions. Consider a more distinctive brand phrase in titles.
2. **Competition**: India-focused fresher tools (HireFresher, AIResumeCV, ResumeGyani, Naukri's AI CV generator) lead the search pages seen. Their claims are vendor marketing, not verified ranking data. Differentiate on what QuickResume really has: free PDF export, ATS checker, Hinglish guide.
3. **Bundle size**: main chunk 606 KB, `Build` chunk 519 KB, `jspdf` 391 KB, `html2canvas` 202 KB. Confirm the export libraries load only on export; measure real Core Web Vitals in Search Console after a few weeks.
4. **Icon font** loads `@tabler/icons-webfont@latest`; pin a version (not verified from here).
5. **Favicon colours** (blue and orange) do not match the logo (navy and gold).
6. **Consent**: custom banner is not a Google-certified CMP. Enable AdSense Privacy & messaging for EEA/UK.
7. **No backlinks measured**; follow the 30-day off-page plan above and read the Search Console Links report.
